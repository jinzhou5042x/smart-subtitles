Privacy Policy

The developers operate no translation server, user account system or analytics service for Smart Subtitles. The extension does not automatically send subtitles, translations or usage reports to the developers. The Software has no advertising or tracking. Its own database and settings are stored on your computer; translation providers process the requests sent to them under their own policies. Information you choose to send in a support request is described below.

Translation requests go directly from your computer to your chosen provider using your account or key. When you select a Google API key file, the program saves its path in local configuration and reads the key to authenticate requests to Google; it does not upload the file itself. Codex manages its own sign-in credentials. Logging out through the extension signs Codex out on this computer and can affect other applications using the same login.

Data the Software uses

  • Subtitle text and timing, and the video title when available, obtained from the supported service to prepare and translate subtitles.
  • Your settings (on/off, target language, translator, subtitle size and position), stored in browser extension storage, and local program configuration such as the selected key-file path.
  • A local access token, created on your computer, that lets the extension talk to the translation program on the same computer. The browser hands it to the extension; it is never sent anywhere else.

The extension does not read your streaming account password or payment details, or collect general browser history. It processes supported video pages to provide subtitles. The local subtitle cache contains content from videos you translated and can therefore reveal what you watched. That cache is not uploaded to the developers.

Where the data goes

  • The extension sends subtitles only to the translation program running on your own computer (address 127.0.0.1), protected by the local access token.
  • Codex: requests to OpenAI include subtitle text and timestamps, the target language, the video title when available, translation instructions, any configured glossary, and previously accepted translations used as context when resuming. They use your signed-in Codex account and its allowance. See OpenAI's Privacy Policy.
  • Google: subtitle text, source and target languages are sent to Cloud Translation. Your API key authenticates the requests, and usage is billed to your Google Cloud account. See Cloud Translation data usage and Google's Privacy Policy.
  • The providers also receive the connection and authentication information needed to serve requests, such as your IP address. Downloads, sign-in pages and links you open connect to the respective third-party services. No project-operated server relays translation requests.

What is stored, and where

The local database stores source subtitles, translations, saved progress and usage counters, including completed portions of unfinished translations. Logs are also stored locally. To remove cached subtitles and logs, first stop the program, then delete its data and logs folders. Uninstalling the extension removes its browser settings, but does not delete the program's files.

Program settings and the local access token are stored separately in config/local.json. Your selected Google key file and Codex-managed sign-in credentials are also separate from the subtitle cache. Use Unlink to remove the key-file association, delete the key file yourself if no longer needed, and use Log out to sign out of Codex. Deleting local files does not delete data retained by translation providers.
