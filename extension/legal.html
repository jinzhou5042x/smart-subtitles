Smart Subtitles

User guide · Chrome Web Store · Downloads

Install the extension, open a supported video with English subtitles, and choose your language. All connections run from the extension on Windows, macOS and Linux. Browser translation needs no account; Chrome may ask you to download a language pack. To use your ChatGPT plan, choose Continue with ChatGPT in Translator settings. See the user guide for setup.

Privacy Policy

The developers operate no translation server, user account system or analytics service for Smart Subtitles. Subtitles, translations and usage reports are not automatically sent to the developers. The extension has no advertising or tracking.

Data the Software uses

  • English subtitle text and timing, and the video title when available, read from supported players to translate and display captions.
  • Your settings and API credentials, kept in this browser profile's extension storage. They are not synced to other browsers. API keys are accessible to the extension's own settings page and background worker, not to video-page scripts or content scripts.
  • Cached translations, stored in the extension's IndexedDB, with subtitle identifiers and timing. Cache identifiers are hashes of the video session, source cue, target language and translator settings.
  • ChatGPT account metadata: your verified account identifier and email, issued application registration ID, a random stable identifier for this browser profile, selected model and welcome acknowledgement are saved locally. They let you choose a saved account for later sign-in.
  • ChatGPT credentials: access, refresh and ID tokens, granted scopes and expiry information stay only in a dedicated worker's memory. They are not written to Chrome storage or exposed to video pages. They are lost when Chrome fully exits or the extension reloads.

The extension does not read streaming account passwords or payment details, or collect general browser history. It processes supported video pages. Cached subtitle content can reveal what you watched.

Where the data goes

  • Browser translation: Chrome translates subtitle text locally. Chrome downloads the required translation components and language packs from its own services. The extension does not send the dialogue to a cloud translator in this mode. See Chrome's Translator API documentation.
  • Google Cloud: the extension sends subtitle text and source/target languages directly to Cloud Translation Basic v2, authenticated with your key. Usage is billed to your Google Cloud account. See Cloud Translation data usage.
  • OpenAI, DeepSeek, Claude, Qwen, or a custom API: requests go directly to the API server you configure. They include the requested dialogue, nearby dialogue and any saved translations as context, the target language, the video title when available and translation instructions. An API key is sent to that server to authenticate requests. A local model uses the local server you provide. Cloud providers process requests under their own account terms and privacy policies.
  • ChatGPT subscription: sign-in and token renewal go directly to auth.openai.com. Translation requests go directly to api.openai.com, with subtitle windows, nearby dialogue and saved translations as context, the video title when available, target language and instructions. Requests use store: false; provider retention is governed by OpenAI's Privacy Policy and your account terms. Translation uses the ChatGPT allowance you authorize.
  • Sign-in callback: during login, a temporary Chrome rule redirects the exact 127.0.0.1:1455/auth/callback navigation in the sign-in tab to an extension page. It receives the one-time authorization code, checks the pending login and clears the URL query. No local server or native application is started. The rule is removed after completion, cancellation or timeout.
  • External providers receive connection and authentication information, including your IP address. Links, downloads and sign-in pages connect to the respective third parties. No project-operated server relays translation requests. The extension does not automatically switch to a paid provider.

What is stored, and how to remove it

Completed translations are cached in the browser, with a limit of 30,000 subtitle lines. Translator settings → Clear saved translations removes this cache. Remove key removes the selected provider profile and its key. Settings and keys use local browser storage, not a separate encrypted vault. Uninstalling the extension removes its browser storage.

Sign out immediately discards this extension's in-memory credentials for the selected ChatGPT account and asks OpenAI to revoke its refresh token. If remote revocation cannot be confirmed, the settings page says so. You can also manage the connection in ChatGPT usage settings. Other applications' logins are independent. Non-secret account metadata remains for later sign-in; uninstalling removes it. Removing local data does not delete provider records, OpenAI website cookies or Chrome's shared language packs.
